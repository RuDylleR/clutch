# Clutch

Статический сайт: HTML + CSS + JavaScript, без сборки.

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Главная: hero, калькулятор, превью авто, автоклубы |
| `cars.html` | Каталог авто с поиском, фильтрами и сортировкой |
| `car.html` | Страница одного авто: `car.html?id=...` (данные из `cars.json`) |
| `style.css` | Все стили (компоненты по порядку, адаптив в конце) |
| `script.js` | Шапка и футер, время, калькулятор, карточки авто, меню |
| `cars.json` | **Данные авто.** Главная и каталог читают этот файл |
| `images/` | Фото авто |

## Запуск локально

`cars.json` загружается через `fetch`, а браузер блокирует это, если открыть
`index.html` двойным щелчком (адрес `file://`). Запускай через локальный сервер:

- VS Code: расширение **Live Server** → «Go Live»;
- или в папке проекта: `python -m http.server 8000`, затем http://localhost:8000.

На GitHub Pages и любом хостинге это работает без доп. настроек.

## Как добавить авто

Добавь объект в `cars.json` (фото положи в `images/`). Страница авто и карточки появятся сами:

```json
{
    "id": "skoda-superb",
    "brand": "Skoda",
    "model": "Superb",
    "year": 2003,
    "engine": "2.0 л",
    "transmission": "МКПП",
    "drive": "FWD",
    "power": 115,
    "weight": 1400,
    "image": "images/skoda-superb.jpg",
    "featured": false
}
```

- `id` — адрес страницы авто (`car.html?id=skoda-superb`). Только латиница, цифры и дефис,
  **уникальный** у каждого авто. Не меняй у существующих: сломаются старые ссылки.
- `transmission`: `МКПП` или `АКПП`; `drive`: `FWD`, `RWD` или `AWD`
  (эти значения совпадают с вариантами в фильтрах на `cars.html`).
- `"featured": true` показывает авто на главной (первые три).
- Запятые между объектами обязательны, после последнего объекта запятой нет.

Необязательные поля — показываются на странице авто, только если заполнены:

| Поле | Пример | Что показывает |
| --- | --- | --- |
| `torque` | `184` | Крутний момент, Нм |
| `acceleration` | `10.9` | Розгін 0–100, с |
| `owner` | `"Влад"` | Власник |
| `city` | `"Охтирка"` | Місто |
| `description` | `"Стоковий седан..."` | Текст о машине под характеристиками |

## Связка каталог ↔ калькулятор

Ссылки с подстановкой значений (id берётся из `cars.json`):

- `index.html?car=chevrolet-evanda#calculator` — открывает «Один автомобіль» с данными авто;
- `index.html?compare=chevrolet-evanda,skoda-superb#calculator` — открывает «Порівняння» с двумя авто.

Их формируют кнопки «Порівняти» на карточках каталога (панель внизу), кнопки на странице авто
и выбор «Авто з каталогу» в самом калькуляторе. Новые авто попадают туда автоматически.

## Ссылки на Discord и Telegram

Хранятся в одном месте: `SITE_LINKS` в начале `script.js`. Discord-приглашение
живёт 30 дней — при замене меняй только строку `discord` там; в HTML и в футере
ссылка подставится сама.

## Шапка и футер

Они в одном месте: в начале `script.js` (`NAV_LINKS`, `renderHeader`, `renderFooter`).
В HTML-страницах стоят только пустые `<header data-site-header>` и `<footer data-site-footer>`.

## Форма «Додай своє авто» (submit.html)

Кнопка веде з `cars.html` на `submit.html`. Логіка — розділ «Форма» в `script.js`, налаштування — константа `SUBMIT_FORM` на початку цього розділу.

**Поки `SUBMIT_FORM.url` порожній**, форма після заповнення показує готовий текст заявки і шматок для `cars.json`: його можна скопіювати й надіслати в Telegram/Discord. Нічого налаштовувати не треба.

**Щоб заявки приходили на пошту**, підключи сервіс форм (безкоштовні плани):

- Formspree (50 заявок/міс): створи форму на formspree.io і встав `url: "https://formspree.io/f/XXXXXXXX"`.
- Web3Forms (250 заявок/міс): отримай access key на web3forms.com і встав
  `url: "https://api.web3forms.com/submit", extraFields: { access_key: "ТВІЙ_КЛЮЧ" }`.

Завантаження файлів у безкоштовних планах немає, тому фото просимо посиланням або в чат.
Захист від спаму: прихований honeypot-рядок і перевірка часу (швидше 3 секунд — не відправляється).

**Як додати авто з заявки:** у листі є поле `cars_json` — готовий об'єкт для `cars.json`. Поклади фото в `images/` з назвою з поля `image` і додай об'єкт у масив.
